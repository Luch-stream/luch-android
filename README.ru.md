# Luch — приёмник экрана с низкой задержкой для Android TV и проекторов

[English version](README.md)

Luch («луч») превращает Android TV, приставку Google TV или проектор в экран, на который компьютер может
транслировать изображение, как в AirPlay и Chromecast, но открыто и с минимальной задержкой. Здесь — **приёмник**
(Android). Отправитель для Linux — [luch-linux](https://github.com/Toxblh/luch-linux).

- **Как AirPlay и Cast.** Приёмник всегда включён и объявляет себя в локальной сети (`_luch._tcp`), отправитель
  находит его и начинает сеанс.
- **Задержка как у Moonlight.** UDP-фрагменты без джиттер-буфера: кадр уходит в аппаратный декодер, как только
  собран, и выводится, как только декодирован; потери восстанавливаются запросом IDR; декодер настраивается всеми
  известными ключами низкой задержки, у дисплея запрашивается игровой режим. На проекторе с чипом MediaTek (MStar)
  от захвата до декодирования около 13 мс на HEVC.
- **Знает своё железо.** После установки измеряет каждый аппаратный декодер (H.264, HEVC, VP9, AV1) и сообщает
  отправителю, какой быстрее, а также размеры, частоты кадров, 10 бит, HDR и форматы звука.
- **Работает рядом с VPN.** Всё идёт через интерфейс, на котором найден ТВ, а не через маршрут по умолчанию.
- **Лёгкий.** Около 6 МБ памяти в покое; без сервисов Google, без аналитики, ничего кроме локальной сети.

## Установка

Скачайте APK из [Releases](https://github.com/Luch-stream/luch-android/releases) (или соберите, см. ниже) и поставьте
через adb:

```sh
adb install luch-release.apk
# запустить сейчас (дальше он запускается сам при каждой загрузке):
adb shell am start-foreground-service -n ru.toxblh.luch/.LuchService
# разрешить показывать картинку, когда отправитель начинает трансляцию (в Android TV для этого нет экрана настроек):
adb shell appops set ru.toxblh.luch SYSTEM_ALERT_WINDOW allow
```

**Luch** в списке приложений ТВ показывает имя и адрес ТВ, подключённых и найденных в сети отправителей.


APK со страницы Releases обновляется сам: раз в день проверяет GitHub и предлагает новую версию на этом экране. Первое
обновление Android попросит подтвердить (и разрешить Luch устанавливать приложения), следующие ставятся сами, пока
ничего не играет. Сборки из F-Droid или магазина обновляет магазин. Подробности: [docs/updates.md](docs/updates.md).

## Версии Android

Android 5.0 и новее, один APK. На Android 8.0+ работает всё; на старых — с ограничениями, о которых приёмник сам
сообщает отправителю (`limits` в welcome, [PROTOCOL.md](PROTOCOL.md), раздел 5), чтобы тот мог их показать:

| Android | Что хуже |
|---|---|
| 11+ | ничего |
| 8.0–10 | нет режима низкой задержки декодера и игрового режима экрана (Android 11); режим низкой задержки Wi-Fi — с 10 |
| 7.x | то же |
| 5.0–6.0 | **звук отстаёт от картинки** на системный аудиобуфер (около 50–150 мс; Android 7 позволяет урезать его до 20 мс). Отправитель может отключить звук, оставить отставание или попросить придержать картинку под звук (`sync`) |
| 5.x | нет списка режимов экрана; декодеру не передаются ключи низкой задержки |

## Вместе с luch-linux

Поставьте [luch-linux](https://github.com/Toxblh/luch-linux) на компьютер:

```sh
luchctl list                       # приёмники в сети
luchctl mirror "<имя ТВ>"           # трансляция монитора (а также: window, virtual, fast)
luchctl stop "<имя ТВ>"
```

На ТВ кнопка **OK** показывает и прячет статистику (задержка, битрейт, кадры, декодер), **«Назад»** завершает
трансляцию.

## Отчёты о падениях

Если приёмник упал или сессия оборвалась из-за ошибки (нет декодера, нет звука), он сохраняет на ТВ короткий отчёт:
что сломалось, стек вызовов, версию Android, модель ТВ и параметры сессии. Без логов, адресов и имён. Отчёты он
отдаёт только отправителю, который их запросит: тот покажет их вам и предложит оформить issue. Сам приёмник никуда
ничего не отправляет. Подробности: [PROTOCOL.md](PROTOCOL.md), раздел 6.

## Сборка

JDK 17 и Android SDK (platform 34):

```sh
cd android
./gradlew assembleFdroidRelease                    # без подписи, как собирает F-Droid (без самообновления)
./gradlew assembleGithubRelease -PluchDebugSign    # с debug-ключом, для adb install
```

Сборок три: `github` (APK со страницы Releases, обновляет себя сам), `fdroid` и `play` (их обновляет магазин; кода
и разрешения для самообновления в них нет).

Клипы для замера декодеров в `android/app/src/main/assets/bench` делает `tools/gen_bench.sh` (тестовая таблица
ffmpeg); `tools/testsend.py <ip ТВ>` шлёт тестовую картинку на приёмник без luch-linux.
